# Ihor Lavrov - Personal Website

A modern, responsive personal portfolio website built with React, TypeScript, and Vite.

## 🚀 Features

- **Modern Design**: Clean, professional design with smooth animations
- **Responsive Layout**: Optimized for all devices and screen sizes
- **Fast Performance**: Built with Vite for lightning-fast development and builds
- **TypeScript**: Full type safety and better development experience
- **Smooth Navigation**: Smooth scrolling between sections
- **Contact Form**: Interactive contact form for potential clients and employers

## 🛠️ Tech Stack

- **Frontend**: React 19 + TypeScript
- **Build Tool**: Vite
- **Styling**: CSS3 with modern features
- **Fonts**: Inter (Google Fonts)
- **Deployment**: Ready for any static hosting service

## 📱 Sections

1. **Hero Section**: Introduction and call-to-action
2. **About**: Personal information and statistics
3. **Skills**: Technical skills and technologies
4. **Projects**: Portfolio of featured projects
5. **Contact**: Contact information and form
6. **Footer**: Additional links and social media

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone <your-repo-url>
cd ihor-website
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

### Building for Production

```bash
npm run build
```

The built files will be in the `dist` folder, ready for deployment.

## 🎨 Customization

### Personal Information

- Update the content in `src/App.tsx` with your personal information
- Modify the skills, projects, and contact details
- Replace placeholder images with your actual photos

### Styling

- Customize colors in `src/App.css`
- Modify the gradient schemes and color palette
- Adjust typography and spacing as needed

### Adding New Sections

- Add new sections to the navigation in `src/App.tsx`
- Create corresponding CSS styles in `src/App.css`
- Ensure responsive design for new components

## 🌐 Deployment

This website can be deployed to any static hosting service:

- **Netlify**: Drag and drop the `dist` folder
- **Vercel**: Connect your GitHub repository
- **GitHub Pages**: Use the `gh-pages` package
- **AWS S3**: Upload the `dist` folder to an S3 bucket
